# ⌨️ Key Race

A simple and fun browser-based typing speed game built with **HTML, CSS, and JavaScript**.  
Type the displayed words as fast as you can before time runs out!

---

## 🎮 Features
- Random word generation
- Real-time letter highlighting (correct / wrong)
- Countdown before game starts
- Background music and sound effects
- Timer-based gameplay
- Score tracking
- Words-per-minute (WPM) calculation
- Restart functionality

---

## 🕹️ How to Play
1. Click **Start Game**
2. Wait for the **3...2...1 countdown**
3. Type the word shown on the screen
4. Complete the word to move to the next
5. Try to get the highest score before time runs out!

---

## 🧠 Scoring
- Each correct word = **1 point**
- WPM is calculated based on total words typed
- Final score is shown when time ends

---

## ⏱️ Game Rules
- You have limited time to type as many words as possible
- Letters turn:
  - ✅ Green → correct
  - ❌ Red → wrong
- Input disables automatically when game ends
